How to Use Aqua Daily Briefing

👋 Say goodbye to juggling multiple apps! The Aqua Daily Briefing is your personalized work dashboard. It combines your Active Projects, Quick Tasks, and Daily Tasks into one shareable briefing — plus a one-click Weekly Status Report for the steering committee.

Quick Navigation Guide

This app has 5 main sections:

  • 🏠 Briefing: Your personal daily report
  • 📋 Status Report: Team-wide status view
  • 📊 Analytics: Visual data on your work
  • Dashboard: Admin interface to manage your content
  • Help: This guide for using the app

First Time User? Here's What to Do Next

  1. Sign in to the Dashboard: Click "Log In to Dashboard" or go to the Dashboard tab
  2. Link Your Account: Enter your Aqua Network User ID (e.g., 'jdoe')
  3. Start Adding Content: Use the tabs in the Dashboard to add your projects and tasks
  4. View Your Report: Return to the Briefing tab to see your personalized dashboard

Finding Your Way Around NEW

Every page shares a navigation bar at the top: 🏠 Briefing, Dashboard, Status Report, Help, and Admin. While you're signed in, the Briefing and Status Report links point at your own report (your linked Network ID), and opening the Status Report page directly loads your report automatically; signed-out visitors get the plain pages.

Step 1: Admin Dashboard & First-Time Login

Use the Admin Dashboard to manage what appears on your report. There is no software to install — everything runs in the browser.

  1. Go to the Admin Dashboard (or click Dashboard in the navigation bar).
  2. Logging In: Sign in with the email and default password provided by IT.
  3. First Time? After your first sign-in, you'll be prompted to link your account to your Aqua Network User ID (e.g., jdoe). That ID becomes your report address, and your (empty) briefing and status report pages start working immediately.
  4. Recommended: change the default password right away on the Settings tab (see "Change Password" below).

Step 2: Managing Your Content

The Admin Dashboard is organized into four tabs — Active Projects, Quick Tasks, Daily Tasks, and Settings — in the same order the briefing shows them. Content supports Rich Text (Bold, Bullets, Headers) via the editor.

1. Active Projects & Quick Tasks Tabs

Minimal usage suggestion: at a minimum, keep your Active Projects up to date — they are what feeds the Weekly Status Report (Key Projects, On Hold, completion %) and the Project Milestones analytics. Quick Tasks (smaller one-off work items) and Daily Tasks are optional.

These sections support rich data. When adding or editing an item:

  • Rich Text Notes NEW: Use the editor to format your notes with bullet points, bold text, and headers.
  • Multiple Attachments NEW: You can now upload multiple files or add manual links (e.g., SharePoint URLs) to a single task.
  • Assigned To NEW: Pick who owns the item from the dropdown, or choose "Other" to type a name. Unassigned items show as N/A on the Weekly Report.
  • Neutral statuses NEW: Alongside the original stages, items can be Planning, In Progress, or Review — friendlier wording for non-IT departments.
  • Collaborators: Tag teams (e.g., "Design Team") to display a yellow Team badge.
  • Milestones IMPROVED: Add multiple milestones (🏁) per item, each with a Base Complete date, an Est/Act Complete date, and In Progress / On-Hold flags (with an on-hold reason). Check 🚧 Roadblock on a milestone (with a reason) to flag it as blocked — it shows red on the reports and pushes the project to the top of Key Projects. Reorder milestones with the ▲/▼ buttons on each row. Progress like "2/5 complete" shows on the report.
  • Dates: Set Start and End dates. The Last Updated field updates automatically.

2. Daily Tasks Tab

  • Add your top 3-5 focus items for the day.
  • Use the Up/Down buttons to prioritize them.

3. Settings Tab

  • Profile: Set your Display Name and Department — they replace your user ID on the Weekly Status Report header and group you correctly in team reports.
  • Change Password: Update your dashboard sign-in password yourself — enter your current password, the new one twice, and click Change Password. Do this after your first login to replace the default password from IT. (Forgot your password? IT can reset it from the Users page.)

Step 3: Daily Operational Checks NEW

Track the health of your systems or routine tasks directly within any Project or Quick Task.

  • How to Log: Open any item in the Admin Dashboard. Look for the "📋 Daily Operational Check" box.
  • Status Options:
    • ✅ Verified: System is healthy.
    • ⚠️ Issues Found: Requires attention (Note required).
    • ⚪ Not Checked: Placeholder status.
  • History: A log of previous checks is saved automatically, so you can track stability over time.

Step 4: Smart Visual Indicators NEW

The dashboard now visually highlights fresh content so viewers know what's new.

  • ✨ Updated Today: Appears on items edited or commented on today.
  • 🔄 Updated Recently: Appears on items active within the last 7 days.
  • No Badge: Items older than 7 days appear standard.

Step 5: Comments

Stakeholders can ask questions right on your briefing.

  • Public Comments: Viewers can click "💬 View/Add Comments" to chat. The editor supports Rich Text formatting.
  • Managing Comments: Open the item in the Admin Dashboard to review or delete comments.

Step 6: Export to Excel IMPROVED

Need a hard copy? The export feature has been upgraded.

  • Where: Click 📥 Export to Excel in the top nav.
  • What's Included:
    • One sheet per section — Projects, Quick Tasks, and Daily Tasks — in the same order as the briefing.
    • Includes the Assigned To column and the full Milestones list.
    • Includes the full Daily Check History log.
    • Includes Analytics Overview (workload, status breakdown, and project milestone summary) as the first sheet.
    • Automatically strips HTML for clean, readable text cells.
    • Adjusts column widths automatically for readability.

Step 7: Visual Analytics IMPROVED

Switch instantly between list view and visual charts.

  • How to Access: Click "📊 Analytics" in the top nav.
  • Charts Included:
    1. Project & Task Status: Doughnut chart of every status in play.
    2. Priority Breakdown: Bar chart of High/Med/Low items.
    3. Workload Distribution: Pie chart of how work is split across Projects/Quick Tasks/Daily Tasks.
    4. Project Milestones NEW: Doughnut chart of milestone states (Completed, In Progress, Overdue, On-Hold, Roadblock, Not Started) across all your projects.
  • Milestone Progress by Project NEW: A table under the charts shows each project's progress bar (e.g. 2/5 complete), its next milestone with the Est/Act date, and flags any Overdue, Roadblock, or On-Hold milestones in red.

Step 8: Viewing & Sharing Reports

You have two views available based on your needs:

🏠 Briefing

URL: /?report=YOUR_ID

  • Includes: Active Projects, Quick Tasks, Daily Tasks, and Public Comments — with Analytics and Export one click away.
  • Navigation: Active Projects opens expanded; use Expand All / Collapse All in the action bar to see everything at once, and the status filter chips to narrow a section.

📋 Weekly Status Report Builder NEW

URL: weekly-report.html?report=YOUR_ID (or click Status Report in the navigation bar)

  • Minimum to get value: the report is built mainly from your Active Projects, so keep those current. Daily Tasks (shown as Recurring Daily Workload) and Quick Tasks are optional — hide their sections with the toolbar toggles if you don't use them.
  • Builds a steering-committee style status report straight from your live briefing data: overall completion %, status chips, Key Projects with milestones and Assigned To, On Hold, Quick Tasks, Recurring Daily Workload, and Recently Completed.
  • Save Personal Report NEW: Click 💾 Save Personal Report in the toolbar to keep your selected sections, order, and Projects-panel choices with your report — it opens the same way next time, on any device. Enabled only when you're signed in and viewing your own report (it never changes anyone else's saved view), and not on team reports, where the layout comes from the team's saved settings (saving a team doesn't touch individual users' saved views either).
  • Open a team NEW: Everyone can open a saved team from the 👥 Teams… dropdown in the top toolbar (or the chips on the connect screen) — selecting one jumps to weekly-report.html?team=<name> and loads it with its saved settings.
  • Multiple users NEW: Enter several User IDs separated by commas (e.g. jdoe, msmith), or pick a name from the "Add user…" dropdown in the toolbar (shown to signed-in leads/admins) — it lists everyone with a briefing and adds them the moment you select. Each user's report appears as its own section; use the ▲/▼ buttons on the user chips to set the order (× removes one). The PDF starts each user on a new page. weekly-report.html?report=jdoe,msmith auto-connects the whole team.
  • Saved teams NEW: After loading a group of users, click 💾 Create Team in the toolbar and give it a name (e.g. "Engineering") — with a team already open the button reads 💾 Save team and updates it in place. Creating or updating teams requires signing in (on the Dashboard or Admin page) with a lead/admin account or as ckonkol — for everyone else the button is hidden. Teams can be removed on the Admin page (same permission). A team saves its members, the "Merge into one report" setting, and the section checkboxes — opening the team restores all three. With a team open, Save team prefills its name so you update it in place. Saved teams appear as one-click chips on the connect screen and home page, and weekly-report.html?team=Engineering opens one directly. The "Add user…" dropdown is grouped by department and shows display names.
  • Freshness warnings NEW: If a briefing hasn't been updated in over 7 days, its report section (and the PDF) shows a red "Last updated N days ago" warning so stale numbers are obvious.
  • Merge into one report NEW: With two or more users loaded, check "Merge into one report" in the toolbar to combine everyone into a single report — one completion %, one status band, and one Key Projects table sorted across the whole team. Each row gets a small tag showing whose briefing it came from. Uncheck to go back to one section per user.
  • Filters NEW: Tap a status chip, or filter by priority — including High + Medium together — and focus (needs attention, due within 30 days, overdue, no est. date).
  • Project order NEW: The Order dropdown (under ⚙ Options) picks between "Needs attention first" (delayed/roadblocked, then priority, then dates), "My dashboard order" — the exact order you arranged with the Up/Down buttons on your Dashboard — and "Custom (Projects panel)". Your choice is remembered. (The Dashboard no longer re-sorts your list when you save an item — use its "↕ Sort by Status" button if you want that sort.)
  • Projects panel NEW: Click 📂 Projects… (under ⚙ Options) to open a list of every loaded project. Untick a project to hide it from the report, and use ▲/▼ to build a custom order (used when Order is set to "Custom"). The report notes how many projects are hidden. Selections are remembered — and 💾 Save team stores them with the team, along with the order choice, merge setting, and sections, so a steering-committee team reopens with the exact same curated view.
  • Toolbar NEW: Filters, user chips, and section toggles live under the ⚙ Options button (collapsed by default). ⛶ Full width stretches the report across the screen (remembered), and ⤢ Full screen presents it (Esc to exit).
  • Show/hide sections NEW: The Sections row in the toolbar (under ⚙ Options) has a checkbox per section (Completion %, Status of Projects, Key Projects, On Hold, Quick Tasks, Daily Workload, Maintenance, Recently Completed). Uncheck what you don't want — the PDF, web download, and copied email text follow the same choices, and they're remembered for next time.
  • Outputs: Download as a PDF, download a standalone web page, or copy as email text. An .xlsx export can also be dropped on the page as an offline fallback.

Step 9: Team Hub (for managers) NEW

One live page — Team Hub in the navigation bar — that pulls every team member's status report together for management review.

  • All Projects board: every project across all briefings with owner, status, and milestone progress. Use the search box and the team/status/sort filters to find anything fast.
  • Comment & prioritize: signed-in leads/admins can post comments on any project and tag it P1/P2/P3. These live in the hub only — they never change the owner's briefing.
  • Project Ideas: add a new project idea, vote 👍 on others, and move ideas through New → Reviewing → Approved/Dropped.
  • Live Manager Chat: a real-time chat panel for the leadership group.
  • Notifications: the 🔔 bell shows unread chat/comments/ideas since your last visit; enable desktop alerts to get a pop-up while the page is open.
  • Analytics & risk: KPI tiles, status and milestone-health charts, projects-per-owner, and a Risk & Focus board that lists every delayed, roadblocked, or overdue project with the reason.
  • Windows sign-in: the hub lives at managerhub.aquatools.app and signs you in with your Windows account — enter your username (e.g. jsmith) and your normal computer password; Windows itself checks them. Sessions last a year per browser. On the office network, http://aqua94:5096/ also works with the one-click "Sign in with Windows" button.
  • Roles: a first-time sign-in automatically creates a hub account with general (read-only) access and emails ckonkol@aqua-aerobic.com. Manager unlocks comments, priorities, ideas, and chat; admin also opens the Admin panel. The ckonkol account always counts as admin.
  • ⚙ Admin panel: user account management (change roles, enable/disable accounts) and a full activity log — sign-ups, role changes, comments, priorities, and idea activity with who/when.
